=====================================
Sample Input Custom Costs and Limits
=====================================

Overview
--------

This walkthrough uses `sample_input.obj` to compare distance, energy, and
blended costs, then applies directional slope limits to show how the same
graph can appear complete while only supporting travel in one direction on
steep ramps.
